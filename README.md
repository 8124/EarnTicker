# EarnTicker

**把「本月已赚」钉在桌面上的 Windows 托盘小工具。**

A lightweight Windows tray widget that turns your monthly salary into a live, ticking counter — driven purely by keyboard/mouse activity.

点一下任务栏右下角的托盘图标，弹出一张卡片，实时显示五个数字：**本月已赚 / 今日已赚 / 秒薪（含实际口径）/ 喝水时间 / 本日进度**。判断你「在不在工位」的唯一依据是键鼠活跃度，不读取任何其他数据，不发一个网络请求。

## 功能

- **五项实时指标**：本月累计、今日累计、秒薪、喝水（空闲）时间、当日进度
- **六态在岗判定**：按过去 4 分钟键鼠活跃度占比，分为疯狂喝水 / 喝水 / 工作 / 埋头工作四档，外加休息中与午休中
- **加权实际工时**：四档各带倍率（0.1 / 0.5 / 1.0 / 2.0），据此算出「实际时薪」，高于标定显示绿色、低于显示红色
- **时间轴进度条**：整条上班→下班钟面按分钟分段落色，已走过的一段才有暗层底，悬停显示该时段状态
- **悬停看占比**：鼠标移到「本日进度」，展开当日各状态的时间占比
- **休息时段冻结**：午休、下班后、非工作日所有数字停止累加，不会虚增
- **纯本地**：配置与统计落在 `%APPDATA%`，程序内无任何 HTTP / socket 调用

## 指标口径

| 界面 | 算法 | 说明 |
|---|---|---|
| 本月已赚 | 秒薪 × 本月已过计薪秒数 | 按月累计 |
| 今日已赚 | 秒薪 × 今日已过计薪秒数 | 从当天上班时刻起算，与程序何时启动无关 |
| 秒薪 | 月薪 ÷ 当月标定工时 | 固定值，随月薪与班时设置变化 |
| 秒薪 · 实际 | 观测期间已赚 ÷ 实际工作时长 | 分子只算程序真正观测到的班时，与分母同起点 |
| 喝水时间 | 已过计薪时长 − 真正在干活的秒数 | **无系数**，空闲多久就是多久；休息时段只停住、不清零 |
| 本日进度 | (现在 − 上班) ÷ (下班 − 上班) | 整段钟面，含午休，与进度条严格同轴 |

「喝水时间」沿用界面文案，实际含义是**计薪时段内未处于「工作 / 埋头工作」状态的时长**。

## 在岗判定：六态模型

每 100 ms 心跳一次，实际按 ≥1 秒采样：该采样周期内有过键鼠输入记 1，否则记 0。最近 **240 秒**的均值即活跃度，按三条边界分档，每条边界留 2% 滞回防抖。

| 状态 | 活跃度 | 颜色 | 实际工时倍率 |
|---|---|---|---|
| 疯狂喝水中 | < 23% | 深绿 `#1F9E63` | ×0.1 |
| 喝水中 | 23% ~ 50% | 浅绿 `#74D6A3` | ×0.5 |
| 工作中 | 50% ~ 77% | 黄 `#FFC24B` | ×1.0 |
| 埋头工作中 | ≥ 77% | 红 `#E5534B` | ×2.0 |
| 午休中 | 落在午休区间 | 中性暗灰 `#4E5866` | 不计 |
| 休息中 | 上班前 / 下班后 / 非工作日 | 灰 `#6E7789` | 不计 |

活跃度由 Win32 `GetLastInputInfo` + `GetTickCount` 差值算出（`idle_seconds()`），不受系统改时间影响。单次采样间隔超过 3 秒的那一格直接丢弃，避免休眠唤醒后一次性灌入大量样本污染占比。

## 快速开始

**环境要求**：Windows 10/11，Python 3.9+（开发环境为 3.14）。程序依赖 tkinter（Windows 官方安装包默认自带）、Pillow、pystray。

### 直接运行源码

```bash
git clone <your-repo-url>
cd EarnTicker
pip install -r requirements.txt
python EarnTicker.py
```

首次运行月薪默认为 **1 元**（刻意设低，避免误传播真实薪资）。右键托盘图标 → **设置…** → 填入月薪与上下班时段，点保存即写入配置，之后每次启动读取你自己的值。

托盘菜单：**查看本月收入**（双击图标同效）/ **设置…** / **退出**。

### 打包为独立 exe

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm --clean EarnTicker.spec
```

产物为 `dist/EarnTicker.exe`（单文件、无控制台窗口、内嵌图标，约 33 MB）。`EarnTicker.spec` 中已声明 `hiddenimports=['pystray._win32']`，缺这一项会导致打包后托盘图标不出现。

## 配置

### config.json

| 字段 | 类型 | 默认值 | 含义 |
|---|---|---|---|
| `monthly` | float | `1.0` | 月薪 |
| `start_hour` | float | `9` | 上班时刻（小时制，`8.5` = 08:30） |
| `end_hour` | float | `18` | 下班时刻 |
| `lunch_hour` | float | `11.5` | 午休开始 |
| `lunch_hours` | float | `1.5` | 午休时长 |

标定工时 = (下班 − 上班) − 午休时长，下限 1 小时；午休区间会自动夹到班时范围内。当月工作日数按**周一至周五**计算。

### 数据文件位置

全部位于 `%APPDATA%\EarnTicker\`：

| 文件 | 用途 |
|---|---|
| `config.json` | 月薪与班时配置 |
| `presence.json` | 当日累计（工作时长 / 真实工时 / 观测时长 / 时间轴） |
| `crash.log` | 启动与异常日志，每次启动追加 |
| `app.pid` | 单实例锁，配合 Win32 事件 `EarnTicker_Show_Event_v2` 唤醒已有窗口 |
| `EarnTicker.ico` | 打包运行时自动释放的图标 |

`presence.json` 按天滚动，跨天自动重置。

## 隐私

程序只读取两项本机信息：**键鼠空闲秒数**与**系统时钟**。不联网、不上报、不读窗口标题、不做屏幕截图。薪资配置仅存于本机 `%APPDATA%`，仓库与发行包中不含任何个人数据。

## 项目结构

```
EarnTicker/
├── EarnTicker.py     # 全部逻辑（单文件，约 1900 行）
├── EarnTicker.spec   # PyInstaller 打包配置
├── EarnTicker.ico    # 应用与托盘图标
├── requirements.txt
└── dist/             # 构建产物（已被 .gitignore 排除）
```

单文件内部按区块组织：调色板 → Win32 辅助（DPI / 窗口圆角 / 任务栏）→ 空闲检测 → 配置与日志 → `PresenceTracker`（采样与六态判定）→ `Engine`（计薪与各项指标）→ 格式化 → 图形资源（PIL 绘制胶囊 / 进度条 / 卡片）→ `Pill`（画布按钮）→ `Popup`（卡片窗口与悬停气泡）→ `App`（托盘与 100 ms 主循环）。

## 已知取舍与限制

1. **仅支持 Windows**：强依赖 `GetLastInputInfo`、`GetTickCount`、任务栏位置探测等 Win32 接口。
2. **时间轴只记录进程存活期间**：程序未运行的空档在进度条上显示为「休息中」，但喝水时间仍按钟面口径计入该空档。两者口径不同是刻意设计：条形只画观测到的，数字要算实际发生的。
3. **工作日不识别法定节假日与调休**：只按周一至周五统计。
4. **倍率只对之后的采样生效**：修改系数后，`presence.json` 中已累计的旧值不会重算。
5. **极端情况下的高值属数学结果**：长时间停留在「疯狂喝水中」（×0.1）会让实际时薪达到标定的约 10 倍，这不是计算错误。
6. **无自动更新、无开机自启**：需要开机自启时，自行将 exe 快捷方式放入 `shell:startup`。
